# Talk / Lecture Mode

For talks, lectures, workshops, guest speakers, keynotes and briefings. One primary speaker, an audience listening.

## Template

```markdown
# {Event or Series} - {Talk Title}
**Speaker:** {Name + title}
**Organization:** {Host organization / location}
**Topic:** {As stated by the speaker or the event listing}
**Format:** Talk + Q&A / workshop / panel segment / site visit / etc.
**Transcripts processed:** {note if part 1 / part 2 / full session}

---

## 1. {First major section - usually framing or housekeeping if covered}

{Cleaned content. Preserve the speaker's specific phrasings as quotes.}

---

## 2. {Next major conceptual block}

**{Sub-theme or key claim}**

{Cleaned narrative. Bullet structure when listing.}

**Key reframe / counterintuitive claim from {Speaker}:**
- {Direct quote or close paraphrase}
- {Why it matters / what it inverts}

**Counterexample raised:**
- {Speaker's counterexample preserved with substance, not just label}

---

## 3. {Continue by conceptual section, not chronologically}

...

---

## Unresolved questions / open threads

{Things the speaker explicitly left open. Things that point to a follow-up talk or session.}

- {Question or open thread #1}
- {Question or open thread #2}

---

## Items referenced for follow-up

{Readings not yet discussed, slides they skipped, links they gave.}

---

## Attribution questions

{Only if unclear speaker moments. Usually one main speaker in this mode, so often empty.}
```

## Mode-specific rules

- **Organize by concept, not chronology.** If the speaker circled back to a topic 30 minutes later, merge it into the same section. The reader wants the structure of the ideas, not the order of utterance.
- **Preserve specific framings as quotes.** When a speaker inverts something, names something, or coins a phrase ("TechFin not FinTech," "compliance ceiling"), quote it verbatim. These are anchors the user will cite later.
- **Counterexamples are gold.** When a speaker raises a counterexample to make a point, preserve both sides - the original claim and the counterexample. Don't collapse them.
- **Open threads matter.** Speakers often signal what comes next at the end. Always include an "Unresolved questions / open threads" section.
- **Slide mismatch.** If reference slides are attached and they don't match what the speaker said, the speaker wins. Note the gap if it changes meaning.
- **Multiple speakers.** Track who's saying what. Each speaker's name in the header. Quotes attributed to the person, not generic "the speaker."

## Naming

`{Event_or_Series}_{Topic}_{Date}.md`

Examples:
- `DataSummit_PricingKeynote_Mar12.md`
- `OpsGuild_WorkshopForecasting_Apr03.md`
- `LeadershipSeries_Session4_May20.md`

If the user already uses a naming pattern in the project, match it.
