# linkedin-connection-note

**Use it when** you need a LinkedIn connection request note that fits the character limit.

## The problem

LinkedIn caps a connection note at 300 characters. Drafts that "looked about right" came out at 310 and had to be trimmed by hand. The drafts also defaulted to a pitch, with numbers from a past job crammed in, which reads as desperate in a cold note.

## What it does

1. Gets the recipient's name, title, company and the context, and verifies them. It never drafts to a guessed name.
2. Picks one angle: the person who owns the team, a peer in the same function, or a local or colleague connection.
3. Writes one real hook and one small ask.
4. **Counts the characters with code** and trims until the count is 300 or under.
5. Delivers each note in its own code block with the verified count underneath.

## Rules it keeps

- The 300-character cap is fixed. A note that reads well at 301 gets cut.
- Connection first, pitch never. No metrics in a cold note. Proof points belong in the follow-up after they accept.
- You send everything yourself. It doesn't send or connect on your behalf.

## Set it up for yourself

The **Voice** section in `SKILL.md` describes my tone. Replace it with yours.

## Limits

- Connection requests only. Follow-up messages and recruiter outreach are out of scope.
- It needs code execution to count characters.
